# DMart Smart Retail Analytics Dashboard (Excel)

## Project overview
An Excel-based retail analytics dashboard built from a 25,000-row DMart dataset.

## Workbook contents
- `dmart dashboard` — main dashboard view with KPI cards and charts
- `kpi data` — KPI summary data
- `dmart_project_bk2` — source dataset (25,000 rows; 31 columns)
- Supporting analysis sheets for revenue by category, revenue by state, order status, and payment analysis

## Dashboard KPIs shown
- Total Revenue: ₹1,69,54,109.33
- Total Orders: 25,000
- Cancellation Rate: 7.14%
- Return Rate: 5.40%

## Excel features present
- 6 embedded charts
- 6 PivotTables
- 5 slicer objects
- Pivot-based category, state, order-status, and payment analysis

## How to use
1. Open the workbook in Microsoft Excel.
2. If prompted, enable editing and refresh the PivotTables if needed.
3. Use the slicers on the dashboard to filter the analysis.
4. Keep the source data structure intact when refreshing PivotTables.

## Notes
This repository contains the workbook, not the original data source documentation. Verify that you have permission to publish or share the underlying dataset before making the repository public.
